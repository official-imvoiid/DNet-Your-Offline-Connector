# DNet design kit

| Folder or file | What it is |
|---|---|
| `screens/` | 18 PNG images of the final design, 1170 x 2532 px each |
| `reference-html/` | The same 18 screens as HTML files. Open any of them in a browser. These hold the exact colours, sizes and text. |
| `design-spec.md` | The design in words: colours, type, components, navigation, what each screen does, and the product rules |

The screens are numbered in the order a person meets them: 01 Welcome through 18 Privacy and security.

"DNet" is a working name. Check that it is free to use before you publish anything under it.
